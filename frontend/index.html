How it is done

📷 Webcam→ 📨 Local API→ ✋ MediaPipe→ 🧠 SigLIP2 model→ ✅ Confidence check→ 💬 Result
  • The webpage takes a photo from the webcam and sends it to a small program (an API) running on the same laptop.
  • MediaPipe, a free Google tool, finds the hand and crops the photo to it. If there is no hand, you are asked to try again.
  • An AI model called SigLIP2, trained on ASL signs, scores the photo against each sign and picks the highest.
  • If the best score is below about 70%, the page says "not sure, try again" instead of guessing.
  • Everything runs on the laptop, so no photos leave it and it works without internet.
  • The statistics are saved in a small file on the laptop, so they are still there after the page or the laptop is closed and opened again.
